Why aikoql?

The only database built from the ground up for the agent era. Not a better Postgres. Not a better vector DB. A new category.

📦

Context Compiler

40-60% reduction in agent discovery tokens. Compiles your code + docs + ADRs into minimum sufficient context packages under a token budget. No other database has this.

🔐

Encryption at Rest v0.2

AES-256-GCM + ChaCha20-Poly1305. Envelope encryption (KEK→DEK→Data) wired end-to-end in serve: [encryption] TOML config, AIKOQL_PASSPHRASE env, keygen v2 key envelope, field-level policies per type. Wrong passphrase fails closed — never silent plaintext.

📝

aikoql — SQL for Knowledge Objects

MATCH, WHERE, SIMILAR TO, SCORE BM25 USING EMBEDDING, TRAVERSE — graph, vector, and text search composed in one statement. Familiar to SQL users, built for knowledge.

🕸

Knowledge Graph + Hybrid Search

Force-directed visualization. Vector (HNSW) + Text (BM25) hybrid search with RRF fusion. Graph traversal with depth and direction. Relationship-first queries.

⚡

Active Knowledge Objects

9 executable KO types: Program, Workflow, Policy, Agent, Trigger, Connector, View, Report, Benchmark. All share the same lifecycle: identity, versioning, provenance, ACL, audit.

📄

Documents → Knowledge Objects

Upload PDF/DOCX/Markdown → OCR → structure analysis → section classification → queryable Knowledge Objects. ADRs become decisions agents can reason over.

🔌

4 Database Connectors

PostgreSQL, SQLite, MongoDB, Neo4j. Import schema and data into the knowledge graph with one command — tables and collections become typed Knowledge Objects.

🛡

Constraint Engine

Property types, uniqueness, cardinality, domain and check constraints — enforced at commit, programmable in aikoql. Agent writes that violate the schema never land.

📡

MCP + REST + Studio

MCP tools over stdio/TCP. 40+ REST endpoints with OpenAPI 3.0. 14-panel Studio UI — no npm, no build step. Zero external dependencies.

💾

Self-Contained Binary

Single file: 3.4 MB (Windows), 3.7 MB (Linux musl). Zero runtime deps. Embedded storage: aikoql-v2 segmented LSM by default (redb / aikoql v1 as profile engines). CLI, server, Studio UI, and shell — all in one binary.

🧩

4 Language SDKs

Python (PyO3 native + pure MCP client), TypeScript, Go (stdlib), Java (Gson). Unified Agent.connect() that auto-detects embedded vs server mode.

🏗

Agent Knowledge Interface

Knowledge primitives with authority, scope, evidence, and lifecycle. Markdown and Rust compilers. Conflict detection, staleness detection, change reconciliation — knowledge that stays current with your repo.

🧬

Epistemic Status Model v0.3

Every fact carries how we know it's true: observed → asserted → verified → contradicted → superseded, over a constrained 7-state transition table. Append-only epistemic history. Agents can't silently flip truth states.

⏱️

Bitemporal Knowledge v0.3

Valid-time (valid_from/valid_to) plus MVCC commit-time. Ask what was true at any moment: AS_OF, BETWEEN, HISTORICAL, and EPISTEMIC filters in aikoql. Supersession stamps when a fact stopped being true.

🧾

Evidence & Derivation Lineage v0.3

Evidence is mandatory on observation, assertion, and verification. derive() records WHY / FROM WHAT / HOW / BY WHOM / WHEN / WITH WHICH EVIDENCE. trace() answers all six with one call — provenance, not vibes.

⚔️

Knowledge Transactions v0.3

Contradict (with authority snapshots), supersede (valid_to + SUPERSEDES edge), merge, invalidate — with a DERIVED_FROM sweep that stamps every dependent stale. Conflict resolution never silently picks a side.

🎓

Agent Experience Reuse v0.3

record_experience captures outcomes as TTL-bounded, evidence-backed KOs. find_experiences matches them to new tasks under reuse conditions — and compile_context injects the lesson into the next agent's context package.

The aikoql Query Language

Everything is a Knowledge Object. Query it like data.

# Create and query — familiar SQL shape
aikoql> CREATE Employee name == "Alice", dept == "Engineering"
aikoql> MATCH Employee WHERE dept == "Engineering" RETURN name, salary
# Hybrid search — vector + text, fused in one statement
aikoql> MATCH Doc SIMILAR TO "refund window"
          SCORE BM25 USING EMBEDDING RETURN *
# Graph traversal — walk relationships from a set of objects
aikoql> MATCH Person TRAVERSE knows RETURN *
# Temporal — what was true, and when did it change (valid-time + MVCC)
aikoql> MATCH Employee AS_OF 1724025600000 RETURN *
aikoql> MATCH Employee BETWEEN 1724025600000 AND 1724630400000 RETURN *
aikoql> MATCH Employee HISTORICAL RETURN *            # every committed version
aikoql> MATCH Employee EPISTEMIC verified RETURN *    # only verified knowledge

Quick Start

# Interactive shell (in-memory)
aikoql shell :memory:

# Start MCP server + HTTP + Studio UI (fresh path = aikoql-v2 database)
aikoql serve --listen 127.0.0.1:9090 --metrics-addr 127.0.0.1:9091 ./kb

# Ingest your codebase into knowledge base
aikoql ingest-dir ~/my-project

# Print knowledge report for any directory
aikoql report ~/my-project

Connect from Code

from aikoql import Agent
db = Agent.connect("localhost:9090")  # or embedded: Agent.connect("./kb") — aikoql-v2 by default
db.remember({"type_name": "Note", "properties": {"body": "Hello aikoql"}})
result = db.query("MATCH Note RETURN *")
import { AikoqlClient } from 'aikoql-sdk';
const client = new AikoqlClient({ command: './aikoql' });
await client.connect();
await client.remember({ type_name: 'Note', properties: { body: 'Hello' } });
import "github.com/ancku/aikoql-sdk"
client := aikoql.NewClient("127.0.0.1:9090")
client.Connect()
result, _ := client.Remember(map[string]interface{}{"type_name": "Note"})
